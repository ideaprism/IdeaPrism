## 6. Agent SDK 옵션 대조표 (M1 착수 전 확인용)

출처: code.claude.com/docs/en/agent-sdk/typescript · sessions · subagents · streaming-output · headless · cli-reference (2026-10-30 조회). 패키지 `@anthropic-ai/claude-agent-sdk`, Node 18.14+.

**M1 실측 결과 (2026-10-30, SDK 0.3.314 타입 정의·실행으로 확인):** 아래 표의 옵션명은 모두 일치. 추가로 확인된 것 — `tools: string[]`는 도구 집합을 **제한**한다(leader.md의 7개만 노출됨), `settingSources`는 생략 시 CLI 기본(user·project·local)이며 팀 CLAUDE.md는 `project`로 읽힌다, `systemPrompt: {type:"preset", preset:"claude_code", append}`로 메인 세션이 팀장이 된다(D4 성공), 서버 재시작 후 `resume`으로 앞 대화를 기억한다(A3 통과).

| PRD 요구 | SDK 옵션 / API | 비고 |
|---|---|---|
| 작업 폴더 `teams/<팀>` | `options.cwd` | 기본값 `process.cwd()` |
| 추가 접근 폴더(wiki·handoff·board·meetings) | `options.additionalDirectories: string[]` | 그 폴더의 `.claude/` 설정은 안 읽음 |
| 세션 재개 | `options.resume: <sessionId>` | 세션 ID는 `type:"system", subtype:"init"` 메시지와 모든 `type:"result"` 메시지의 `session_id` |
| 도구 승인 콜백(결재) | `options.canUseTool(toolName, input, {signal, toolUseID, ...})` → `{behavior:"allow"}` 또는 `{behavior:"deny", message}` | 권한 규칙·`allowedTools`로 이미 허용된 도구에는 **호출 안 됨** → 10.2 자동 허용은 `allowedTools`로, 나머지는 콜백으로 |
| 도구 제한(5.2) | `disallowedTools` 또는 `tools` | **`allowedTools`는 자동 승인일 뿐 제한이 아님** |
| 중단 버튼 | `query.interrupt()` | **스트리밍 입력 모드(prompt를 AsyncIterable로)에서만 동작** → M1부터 이 모드로 구현 |
| 모델 | `options.model: "sonnet"` | `fallbackModel`도 있음 |
| 텍스트 스트림 | `type:"assistant"` 메시지의 `content` 블록 `type:"text"` | 부분 스트림은 `includePartialMessages: true` + `stream_event` |
| 도구 사용 시작(7.2 매핑) | `assistant` 블록 `type:"tool_use"` (`name`, `input`) | `name`이 Read/Glob/Grep이고 `input.file_path`가 wiki 경로면 `research(wiki)` |
| 도구 결과 | `type:"user"` 메시지의 `tool_result` 블록 | 정확한 형태는 M1 1단계에서 실측 |
| 완료·비용 | `type:"result", subtype:"success"` (`result`, `total_cost_usd`, `usage`) | 토큰 표시(2차)는 `usage`·`modelUsage` 사용 |
| 오류 | `result` subtype `error_max_turns` / `error_during_execution` / `error_max_budget_usd` | `is_error` 확인 |
| CLI 검증 경로(M1 1단계) | `claude -p --output-format stream-json --verbose --include-partial-messages --resume <id> --add-dir <path> --agents <json>` | `--permission-prompt-tool`도 존재 |

**M1 설계 결정 (D4): 팀장을 "메인 세션"으로 띄운다.**
문서상 `.claude/agents/leader.md`는 **서브에이전트** 정의이고, 메인 질의를 특정 에이전트로 실행하는 옵션은 없다. 서브에이전트로 띄우면 응답이 Agent 도구 결과 안에 중첩돼 스트리밍·상태 매핑이 어렵다. 따라서:

| 항목 | 방식 |
|---|---|
| 페르소나 파일 | PRD대로 `teams/<팀>/.claude/agents/leader.md`에 둔다 (`claude` 대화형에서도 쓰이도록) |
| 서버 실행 | 서버가 `leader.md` 본문을 읽어 `systemPrompt: {type:"preset", preset:"claude_code", append: <본문>}`로 넣고, frontmatter `tools`는 `tools`/`disallowedTools`로 옮긴다 |
| 효과 | 메인 세션 = 팀장. 텍스트·도구 사용이 1단 스트림으로 들어와 7.2 매핑이 단순해짐. 세션 재개도 메인 세션 ID 하나로 끝남 |
| 2차 | 팀원(벤·뮤즈) 가동 시 `options.agents`로 서브에이전트 추가 (PRD 미결 #4) |

# 모두의창업 1R 지원규정

- 한 줄 요약: 1R 지원 3가지(1:1 멘토링, 창업활동자금 200만원, AI 솔루션 100만원)의 규칙과 평가 반영 방식
- 출처: `raw/2610/2차 모두의 창업 1라운드 진출자 지원 안내 책자.pdf`
- 갱신일: 2026-10-26
- 관련 페이지: [[모두의창업_일정]] [[모두의창업_제출양식]]

## 평가 반영 (성실성 지표, p.8)
| 지원 | 평가 반영 |
|---|---|
| 1:1 책임멘토링 (필수) | 내용 충실성·성실 참여(2~4회) → **가점** (정성평가). 2회 미만이면 감점 요인 |
| 창업활동자금 | 부적절 사용 시 **감점**. 집행률은 가·감점 없음 (안 써도 됨) |
| AI 솔루션 | 참고자료. 활용 여부로 가·감점 없음 |

## 1:1 책임멘토링 (p.6~8)
| 항목 | 내용 |
|---|---|
| 횟수·시간 | 최소 2회 ~ 최대 4회, 회당 1~3시간. 시작·종료 시각 증빙 필요 |
| 방식 | 온·오프라인 모두 가능. **반드시 1:1** (그룹·강의형은 불인정) |
| 보고 | 회차별 보고서는 멘토가 플랫폼에 작성. 멘티는 마이페이지 > 내 활동보고서에서 확인 |
| 주의 | 무단 불참 반복 시 성실성 반영. 멘토·멘토기관 관련 업체와는 활동자금 거래 불가 |
| 팁 | 논의할 내용을 미리 정리해 멘토에게 전달 |

## 창업활동자금 200만원 (p.9~20)
- 신한 클린 선불카드. 부가세 포함 200만원. 사용 기간: 충전일~11.30
- 개인 카드·계좌이체·현금 결제분은 지급 안 됨. 해외·외화 결제 불가 (원화 결제 경로는 가능)

| 비목 | 예시 |
|---|---|
| ① 재료구입비 | 부품·원자재, 학습·검증용 데이터셋, 소모품 |
| ② 외주용역비 | 앱·웹 개발 외주, 디자인, 홍보 콘텐츠·광고 대행, 시장조사 용역 |
| ③ 문헌구입비 | 도서, 논문, 유료 리포트 |
| ④ 지급수수료 | 생성형 AI 구독료, AI API·토큰(원화 결제 경로만), 개발·테스트용 클라우드, 전시회 참가비, 특허 관납료 |
| ⑤ 여비·회의비 | 국내 교통비·숙박비, 멘토·전문가 미팅 식음료 (주차비·유류비 불가) |

| 증빙 기준 | 내용 |
|---|---|
| 1건 10만원 미만 + 가맹점으로 사용처 확인 | 증빙 면제 (집행 상세내역에는 기재) |
| 1건 10만원 이상 / PG·오픈마켓 결제 | 건별 증빙 필수 (주문상세내역 + 사진) |
| 1건 50만원 초과 | 멘토기관 **사전 승인** 후 집행 |
| 자산성 물품 50만원 이하 | 자산보유서약서, 5년 보유 |
| 숙박비 한도 (1일) | 특별시 10만원 / 광역시 8만원 / 기타 7만원 |

**사용 불가**: 노트북·모니터·태블릿 등 개인용 전자기기, 상품권, 본인·팀원 인건비·식비, 인테리어, 주차료, 특허등록 성공보수, 사업자 지출증빙·부가세 환급, 본인·가족·멘토 관련 업체 거래, 쪼개기 결제

**IDEAPRISM에 해당될 만한 항목 (판단 전 멘토기관 확인)**: AI 구독료·API 비용(지급수수료), 학교 방문 교통비(여비), 교사 인터뷰 회의비(동석자 기재), 개발·테스트용 클라우드. 단순 홈페이지 운영비는 불가

## AI 솔루션 100만원 (p.21~23)
- 플랫폼(modoo.or.kr > AI 솔루션 지원)에 등록된 솔루션만. 1개월 단위 신청, 사후정산
- ChatGPT·Claude 같은 해외 AI 구독료는 해당 안 됨 → 창업활동자금으로 결제
- 신청 기한 후 취소·환불 불가. 공급기업에게서 경품·페이백을 받으면 부정수급

## 제재 (p.4)
| 경우 | 제재 |
|---|---|
| 정당한 사유로 중도 포기 | 잔액 환수 |
| 정당한 사유 없이 포기 | 참여 제한 1년 + 전액 환수 |
| 횡령·리베이트 등 부정 사용 | 참여 제한 3년 + 환수 |
| 아이디어·사업계획 위조·표절 | 참여 제한 3년 |

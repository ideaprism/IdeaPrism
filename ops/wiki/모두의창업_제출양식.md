## 1R 사업계획서 (2R 진출평가의 주요 자료)
- 파일명: `성명_1R 사업계획서` (작성 hwp·docx, 제출 hwp·docx·pdf·zip 중 1개). 붙임 자료가 있으면 함께 압축
- 분량: 본문 A4 **8쪽 이내** (사진·표 포함), 붙임 A4 3쪽 이내 (사진 최대 3장)
- 수치(시장규모, 매출·비용, 소요자금)는 **출처나 산출근거를 함께 기재**
- 문제 → 해결 → 시장진입·성장 → 발전계획이 이어지도록 작성

| 문항 | 작성요령 핵심 |
|---|---|
| Q1. 문제 인식 (Problem) | 착안 계기와 문제 / 목표 고객, 문제의 크기·시급성 (통계·조사·인터뷰 근거) / 시장 규모, 기존 해결방식의 한계 |
| Q2. 실현 가능성 (Solution) | 핵심 기능 / 개발 방법과 준비 정도 (**완료와 예정 구분**) / 경쟁 대비 차별성과 본인 역량 |
| Q3. 성장전략 (Scale-up) | 수익 구조(누구에게, 무엇을, 어떻게)와 초기 진입 전략 / 단계별 일정·목표 (표 권장) / 소요자금과 조달 계획 (산출근거) |
| Q4. 향후 발전방안 (Development) | 중장기 방향 / 기능 고도화 / 시장 확대 / 필요한 기술·인력·협력기관 |

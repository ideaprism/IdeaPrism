# ops — 사업운영 LLM Wiki 스키마

## 원칙
- 사람은 `raw/`에 넣고 질문만 한다.
- `wiki/`는 Claude만 쓴다.
- `raw/`는 절대 수정하지 않는다.

## raw/ 규칙
- 월별 하위 폴더 (예: `raw/2611/`)
- 파일명: `YYMMDD_출처_주제`

## wiki 페이지 형식
맨 위에 다음 항목을 둔다.
- 제목
- 한 줄 요약
- 출처 (raw 경로 또는 URL)
- 갱신일
- 관련 페이지 `[[링크]]`

## wiki 구조
- `wiki/` 하위 폴더는 만들지 않음. 페이지 20개 초과 시 사용자와 상의 후 분리
- `index.md`: 페이지당 한 줄 (링크 | 요약 | 갱신일)
- `log.md`: 추가만 함. 형식 `YYYY-MM-DD [회사/집] 작업종류: 내용`

## 작업 3종
| 작업 | 내용 |
|---|---|
| Ingest | raw의 새 자료를 읽고 관련 wiki 페이지 생성·갱신. 자료 간 모순은 표시. index·log 갱신 |
| Query | wiki 근거로 답하고 출처 페이지 표시. 가치 있는 답은 새 wiki 페이지로 저장 |
| Lint | 모순, 오래된 정보, 끊긴 링크, index 누락 점검 후 보고·수정 (집 PC에서 주 1회) |

## out/ 규칙
- 사업계획서 등은 wiki를 근거로 작성하고, 수치·주장마다 출처 표시
- 하위 폴더 예: `out/모두의창업_2R/`

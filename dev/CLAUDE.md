# dev — 개발 + DB

## DB 작업 흐름
| 단계 | PC | 작업 |
|---|---|---|
| 1 | 회사 | `db/`에서 가공 워크플로우와 `prompts/` 완성, `data/sample/`로 테스트 |
| 2 | 집 | `data/raw/` 전체를 전처리해 `data/processed/`에 저장 |
| 3 | 회사 | processed로 `index/`에 색인 |

## 데이터 규칙
- `data/raw/`는 집 PC에만 둔다 (Git 제외)
- sample은 유형별로 고르게 100건
- processed 생성 후 용량 확인. 파일 하나가 100MB 초과면 Git으로 옮기지 말고 사용자에게 알릴 것

## 보고
- 개발·DB 진행 결과는 `ops/wiki/개발현황.md`에 요약 (사업계획서 근거용)

## 작업 방식
- 사용자는 비개발자. 실행 전 무엇을 하는지 한 줄로 설명
- 파일 삭제나 대량 변경은 먼저 확인받기
